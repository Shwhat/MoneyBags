# Release notes

The installed version is shown at the top of this guide.

## 1.0.0 (2026-11-17): First release

- Shared expense book for two people, with accounts, sign-in and one editor at a time.
- Expenses with date, vendor, category, who paid, joint (Y) or for the other person (N), amount, cash back, amount saved and notes.
- Entry row for typing expenses one after another, vendor suggestions and category recall.
- Balance today, per month and per year, using the same rules as the old Monthly Expenses sheet, rounded to whole cents per expense.
- Settle-up payments, credits and adjustments.
- Recurring bills, including bills whose amount changes each month.
- Categories that can be renamed, reordered and deleted.
- Summary view with the month-by-month table and category totals.
- Charts of each person's share, spending by category and the balance.
- To-do panel for expenses that need a look.
- Import from the old Excel workbooks, with duplicate checks and review flags.
- Export to CSV and Excel; backup download and restore; 60 daily server backups.
- Ribbon, menus, dockable panels, workspaces, command line, keyboard shortcuts, light and dark themes.
- Demo book and this guide.
- Docker image for amd64 and arm64, ready for a Dockhand Git stack.
