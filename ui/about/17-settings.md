# Settings

MoneyBags has settings that belong to the shared book and preferences that belong to each account.

## Book settings (shared)

**File > Book settings...** (or **Book settings** on the Data tab).

| Setting | Default | Notes |
|---|---|---|
| First person | Set up on first run | The name used everywhere for person 1 |
| First person letter | First letter of the name | Matches the Who Paid column when importing; up to 3 letters |
| Second person | Set up on first run | |
| Second person letter | First letter of the name | Must differ from the first person's letter |

Names and letters change for both people and can be undone.

## Preferences (per account)

| Preference | Choices | Default | Where |
|---|---|---|---|
| New expenses are paid by | The signed-in person, first person, second person | The signed-in person | Book settings |
| Theme | Light, Dark, Same as the computer | Light | Book settings, View menu, View tab, right-click on the ribbon |
| Panels and their places | Any arrangement | Entry workspace | Dragging panels; View menu |
| Workspaces | Built-in and saved | Entry | Workspace list; View menu |
| Ribbon | Any tabs, groups and buttons | Default ribbon | Customize ribbon |
| Command line | Shown or hidden | Hidden | View menu, View tab |
| Last view | Expenses, Payments, Recurring bills, Summary or Charts | Expenses | The view in use when the page closed |
| Sort of the expense list | Any column, either direction | Date, oldest first | Column names |
| Open years in the Years panel | Any | The year on screen | ▼ and ▶ arrows |

Preferences are saved on the server for your account (prefs.json), or in the browser without a server. A new version of MoneyBags resets the ribbon to the default so new buttons appear; other preferences stay.

## Theme

- Light and Dark set the colors of the whole program, including the charts.
- Same as the computer follows the operating system and changes with it.
- The sign-in page always follows the computer.
