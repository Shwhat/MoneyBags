# Glossary

| Term | Meaning |
|---|---|
| Book | Everything the two people share: names, categories, expenses, settle-up entries and recurring bills |
| Expense | One purchase or bill |
| Joint (Y) | An expense both people share, split in half |
| For the other person (N) | An expense one person paid entirely for the other |
| Personal (P) | An expense that belongs to the person who paid; nobody owes anything |
| Split | Whether an expense is joint (Y), for the other person (N) or personal (P) |
| Final total | Amount minus cash back |
| Cash back | Money back from the credit card on an expense |
| Amount saved | A note of money saved on an expense; it changes no total |
| Share | The part of an expense that belongs to each person |
| Balance | Who owes whom, and how much, after every expense and settle-up entry so far |
| Net | The balance effect of one month or period alone |
| Carried in | The balance at the end of the previous year |
| Settle-up entry | A payment, credit or adjustment between the two people |
| Payment | Money sent from one person to the other |
| Credit | Value given instead of money |
| Adjustment | A correction or an opening balance |
| Recurring bill | A bill that adds one expense each month by itself |
| Needs review | A mark with a reason that lists an expense in the To-do panel |
| Period | The month or whole year on screen |
| Entry row | The row of fields at the top of the Expenses and Payments lists for typing new rows |
| Edit lock | What lets one person at a time change the book |
| Read-only | The book can be seen but not changed |
| Workspace | A saved arrangement of panels |
| Ribbon | The tabs of buttons under the menu bar |
| Contextual tab | A ribbon tab that appears only when it applies (Selection) |
| Panel | A docked or floating box: Years, To-do, Balance or Properties |
| Demo book | A made-up book that is never saved |
| Letter | The short code for a person, matching the Who Paid column of the old workbooks |
| Daily backup | The server's copy of the book from the last save of a day |
