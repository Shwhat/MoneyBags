# Categories

Categories group expenses for the summary and the charts. The list belongs to the shared book, so both people see the same categories.

## The default list

Food, Groceries, Utilities, Travel, Household, Other.

## Choosing a category

- In the entry row, the Properties panel, **Change selected...**, or a recurring bill.
- When a vendor used before is typed in the entry row with no category chosen, the category of that vendor's last expense is filled in.
- Importing from Excel guesses a category from the vendor name; see [Importing from Excel](/about/importing-from-excel).

## Changing the list

**File > Categories...** (or **Categories** on the Data tab) lists every category with the number of expenses in it.

| Button | What it does |
|---|---|
| (name field) | Renames the category |
| ▲ and ▼ | Move it up or down; the order is used in every category list |
| Delete | Deletes it; when expenses use it, a list asks where they move: another category or no category. Confirm applies the choice |
| Add category | Adds "New category" at the end, ready to rename |

**Save** applies every change at once. Names cannot be blank and must be unique. **Insert > Category...** adds one category directly.

## Filtering and totals

- The **All categories** filter in the Expenses view shows one category or the expenses with none.
- The Summary view's **By category** table and the Charts view's **Spending by category** chart total each category for the period on screen. Clicking a row in the table opens the Expenses view filtered to that category.
