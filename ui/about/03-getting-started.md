# Getting started

This page covers the first sign-in, setting up the book and entering the first expenses.

## First sign-in

1. Open MoneyBags in a browser at the address it was installed on.
2. When no account exists yet, the sign-in page opens on **Create account**. Enter a user name and a password of at least 8 characters, repeat the password, and select **Create account**.
3. The second person opens the same address and creates their own account the same way.
4. After two accounts exist, the sign-in page only offers **Sign in**. The account limit is set on the server; see [Accounts and sign-in](/about/accounts-and-sign-in).

## Setting up the book

The first time the book is opened, the **Set up MoneyBags** dialog asks for the two names.

| Field | What it is |
|---|---|
| First person | Filled in from the signed-in user name; change it if needed |
| Second person | The other person's name |

Select **Start**. MoneyBags takes the first letter of each name as that person's letter (for example D and A). The letters are used when importing from Excel. Names and letters can be changed later in **File > Book settings**.

## Bringing in the old spreadsheets

1. Select **File > Import from Excel...** (or **Import Excel** on the Data tab).
2. Choose one or more workbooks.
3. Check the preview and select **Import**.

See [Importing from Excel](/about/importing-from-excel).

## Entering an expense

1. Press **N**, or select **New expense** on the Home tab. The cursor moves to the entry row at the top of the expense list.
2. Type the vendor, then press Tab to move through category, paid by, split, amount, cash back and notes.
3. Press Enter. The expense is added and the entry row clears for the next one. The date, who paid and the split stay as they were.

## Setting up monthly bills

1. Select **Insert > Recurring bill...**.
2. Enter the bill name, the amount (or leave it blank if it changes each month), who pays, the split, the category, the day and the first month.
3. Select **Add bill**.

See [Recurring bills](/about/recurring-bills).

## Settling up

The Balance panel shows who owes whom today. Select **Record settle-up payment...** in that panel to record the payment with the amount filled in.

## Trying things out

**Help > Open the demo book** opens a made-up book that uses every feature. Nothing in it is saved. **Help > Close the demo book** returns to the real book exactly as it was.
