# Keyboard shortcuts

Single-letter shortcuts work when the cursor is not in a text field. Help > Keyboard shortcuts shows this list in the program.

## Adding

| Keys | Action |
|---|---|
| N | New expense (moves to the entry row) |
| P | Record a settle-up payment |
| Enter (entry row) | Add the expense and start the next one |
| Tab / Shift+Tab | Next or previous field in the entry row |
| Escape (entry row) | Clear the entry row |

## Selecting and editing

| Keys | Action |
|---|---|
| Click | Select a row |
| Ctrl+click | Add or remove a row from the selection |
| Shift+click | Select a range of rows |
| Up / Down | Select the previous or next row |
| Shift+Up / Shift+Down | Extend the selection |
| Ctrl+A | Select every row in the list |
| Enter | Edit the selected row in the Properties panel |
| Double-click | Edit the row in the Properties panel |
| Ctrl+D | Duplicate the selected rows |
| Delete | Delete the selected rows |
| Escape | Clear the selection or close About |

## History and saving

| Keys | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+S | Save now |

## Moving around

| Keys | Action |
|---|---|
| Alt+1 | Expenses view |
| Alt+2 | Payments view |
| Alt+3 | Recurring bills view |
| Alt+4 | Summary view |
| Alt+5 | Charts view |
| Page Up / Page Down | Previous or next month |
| Shift+Page Up / Shift+Page Down | Previous or next year |
| Ctrl+F | Search the expense list |
| F1 | About MoneyBags |

## Dialogs

| Keys | Action |
|---|---|
| Enter | Confirm (also from a list or a check box) |
| Escape | Cancel |

## Panels

| Keys | Action |
|---|---|
| Escape (while dragging a panel) | Cancel the drag |
| Alt (while moving a floating panel) | Place it without sticking to edges |
| Shift (while moving a floating panel) | Do not join another panel |

On a Mac, Cmd works in place of Ctrl.
